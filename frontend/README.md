## Frontend

Этот каталог содержит клиентскую часть сервиса (Next.js + React).

### Структура проекта

Проект организован по ролям пользователей для максимальной простоты и понятности:

- `src/app` — **страницы Next.js** и маршруты (login, `student`, `teacher`, `mng` и т.д.).
- `src/teacher/` — компоненты и типы для роли **преподавателя**:
  - `types.ts` — типы для преподавателя (Group, Assistant и т.д.)
  - `components/` — компоненты страниц преподавателя (TeacherNav, MyGroupsSection, AssistantSearchSection и т.д.)
  - `pages/` — компоненты страниц (заглушка для будущих страниц)
- `src/assistant/` — компоненты и типы для роли **ассистента**:
  - `types.ts` — типы для ассистента (Course и т.д.)
  - `components/` — компоненты страниц ассистента (AssistantNav, MyCoursesSection, CourseCard и т.д.)
  - `pages/` — компоненты страниц (заглушка для будущих страниц)
- `src/manager/` — компоненты и типы для роли **менеджера**:
  - `types.ts` — типы для менеджера
  - `components/` — компоненты страниц менеджера
  - `pages/` — компоненты страниц (заглушка для будущих страниц)
- `src/components` — **общие компоненты** интерфейса (Header, ThemeProvider и `ui/` с кнопками, инпутами и т.п.).
- `src/hooks` — пользовательские React hooks.
- `src/lib` — утилиты и вспомогательные функции.
- `src/types` — **общие типы** (например, `User`, `UserRole`), которые используются в разных частях приложения.
- `public` — **логотипы и изображения** (например, `public/logo.png`, используемый на главной и в шапке).

### Скрипты

- `pnpm dev` — запуск dev-сервера фронтенда.
- `pnpm build` — сборка.
- `pnpm start` — запуск собранного приложения.
- `pnpm lint` — проверка кода линтером.
