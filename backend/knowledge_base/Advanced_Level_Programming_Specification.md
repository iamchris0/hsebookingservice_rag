# Спецификация экзамена продвинутого уровня по Программированию

## О спецификации

Спецификация основана на результатах анализа задач, предлагаемых на алгоритмических секциях собеседования на позиции стажера и Junior backend разработчика в ведущих российских и зарубежных IT-компаниях.

### Основные компетенции, проверяемые на экзамене профильного уровня

1. Знание основ программирования (арифметические операции, ветвления, циклы, массивы, множества, словари, функции, рекурсия)
2. Знание и умение использовать для решения практических задач широкого круга классических однопоточных алгоритмов
3. Умение строить математическую модель задачи по её условию
4. Умение оценивать эффективность алгоритма и его применимость при заданных ограничениях
5. Базовые навыки декомпозиции решения задачи
6. Базовые навыки тестирования решения, юнит-тесты
7. Общие IT-компетенции (в первую очередь работа со средами разработки)

### Условия проведения

- На решение экзамена отводится **2 часа**
- Все предлагаемые на экзамене задачи подразумевают написание кода программы, ввод и вывод в которой осуществляется через консоль
- Проверка осуществляется автоматически на заранее подготовленном наборе тестов
- Проверяются ограничения на время выполнения кода программы и потребляемую память на каждом тесте
- Программа может быть написана на одном из языков: **Python 3, C++, C, C#, Java**
- Гарантируется, что все задачи имеют решения на языках C++, C, Java
- Некоторые задачи не могут быть решены на языке Python 3 из-за его низкого быстродействия

## Основные темы задач, предлагаемых на экзамене

1. **Основы программирования** (типы данных, управляющие конструкции, циклы, функции, основы ООП, использование стандартных библиотек)
2. **Использование множеств и словарей**
3. **Сортировка подсчётом, сортировка слиянием, быстрая сортировка**
4. **Жадный алгоритм** (применение для отсортированных последовательностей, определение параметра сортировки)
5. **Порядковые статистики** (поиск за O(n), свойства медианы массива, определение k наибольших чисел за O(n), медиана в скользящем окне)
6. **Стеки, очереди, деки**
7. **Два указателя**
8. **Префиксные суммы**
9. **Двоичный поиск**
10. **Использование сбалансированных двоичных деревьев поиска**
11. **Динамическое программирование** (динамическое программирование с одним и двумя параметрами, задачи НОП и НВП, редакционное расстояние, ДП по подстрокам)
12. **Обход графов в ширину**
13. **Обход графов в глубину** (компоненты связности, наличие циклов, раскраска в два цвета, топологическая сортировка)

## Продвинутый уровень: Спецификация тестовой части экзамена

### Общая информация

- Всего на экзамене **5 задач**, максимальная оценка **10 баллов**
- Задачи оцениваются нелинейно:
  - 1 задача — 4 балла
  - 2 задачи — 5 баллов
  - 3 задачи — 6 баллов
  - 4 задачи — 8 баллов
  - 5 задач — 10 баллов
- Все задачи оцениваются по системе «Всё или ничего» — частично правильных ответов нет
