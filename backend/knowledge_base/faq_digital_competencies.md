### Блок 1.1: Ошибка проверки задания на платформе
**Метаданные:**
```yaml

intent: report_grading_error
regulation_link: Приложение 5, п. 6.2-6.3
```

**Вопросы:**
- Задание не засчитывается, хотя формула правильная
- Система не принимает решение в задании 16
- Почему код не прошёл проверку

**Ответ:**
```
1. Диагностика:
   - Используйте формулу из справки
   - Проверьте работу на всех входных данных

2. Если ошибка повторяется:
   - Сделайте скриншот
   - Обратитесь в учебный офис
   - Приложите подтверждение

3. Важно:
   - Попытка может быть аннулирована
   - Ошибка должна быть зафиксирована

```

> см. Приложение 5, п. 6.2-6.3

```

**Вопросы:**

**Ответ:**
```
