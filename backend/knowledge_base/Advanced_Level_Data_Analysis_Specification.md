# Спецификация экзамена продвинутого уровня по Анализу данных

# О спецификации

Экзамен продвинутого уровня включает себя темы по линейной алгебре, теории вероятностей, статистике, анализу данных и машинному обучению.  
Предполагается, что для решения теста студенты либо используют бумагу и ручку, либо пишут собственный код и используют доступные им языки программирования (язык, на котором разработаны и ожидается решение заданий \- Python).

На выполнение экзамена отводится 3 часа (180 минут). 

### **Структура экзамена**

Математика:

1. Основы теории вероятностей: определение вероятности, базовые понятия и формулы (математическое ожидание, дисперсия), теорема Байеса и формула полной вероятности, формула включений-исключений.  
2. Линейная алгебра: векторные пространства, свойства матриц, матричные разложения.

Статистика:

3. Введение в статистику. Основная терминология.  
4. Сбор данных. Выборка и генеральная совокупность.   
5. Типы переменных. Меры центральной тенденции и разброса. Выбросы.  
6. Частотные таблицы и распределения. Основные виды распределений.  
7. Работа с данными: агрегирование, фильтрация, создание новых переменных.  
8. Визуализация.   
9. Корреляция.   
10. Работа с пропущенными значениями.

Машинное обучение:

1. Основные задачи машинного обучения (классификация и регрессия).  
2. Основы линейной алгебры для МО.  
3. Оценка качества модели. Основные функции потерь.   
4. Улучшение качества модели. Борьба с переобучением. Кросс-валидация. Подбор параметров по сетке.  
5. Основные классические алгоритмы МО: линейные модели, метод ближайших соседей, решающие деревья, композиции моделей.  
6. Задача кластеризации и основные алгоритмы: k-means, DBSCAN.  
7. Особенности работы с текстами (очистка, преобразование, токенизация, лемматизация)  
8. Базовые подходы к работе с изображениями (нормализация, работа с черно-белыми и цветными изображениями)  
9. Основные понятия из глубинного обучения (типы слоев, функции активации и их свойства)

Во время написания экзамена можно будет пользоваться специально разработанным методическим материалом (будет опубликован в курсе Подготовки). Материал будет содержать возможные вариации в терминологии, а также основные формулы.
