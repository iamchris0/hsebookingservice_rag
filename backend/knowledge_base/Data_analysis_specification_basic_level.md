# **Спецификация независимого экзамена по Анализу данных. Базовый уровень. 2025/2026 учебный год.**

## **О спецификации**

Экзамен базового уровня включает в себя темы по статистике, анализу данных и машинному обучению.

Предполагается, что для решения экзаменационных заданий студент может использовать любое статистическое ПО, позволяющее проводить обработку данных, рассчитывать дескриптивные статистики, строить визуализации и оценивать линейные и логистические модели (например, Python, R, Excel, Stata, SPSS).

Во время написания экзамена студент может использовать специально разработанный методический материал. Материал содержит возможные вариации в терминологии, а также основные формулы. 

## **Темы экзамена**

**Работа с данными** 

- Фильтрация  
- Сортировка   
- Агрегирование  
- Создание новых признаков  
- Перекодирование данных  
- Объединение таблиц  
- Создание сводных таблиц  
- Визуализация  
- Обнаружение и работа с пропущенными значениями

**Статистика**

- Шкалы измерения признаков  
- Описательные статистики.  
- Выбросы  
- Корреляция Пирсона и Спирмана  
- Ошибки I и II рода  
- Тестирование гипотез: парный t-тест, двухвыборочный t-тест, Одновыборочный t-тест и Z-тест, U-тест Манна–Уитни, Шапиро-Уилка, Z-тест для пропорций, Критерий хи-квадрат

**Машинное обучение**

- Линейная регрессия (обучение, метрики качества: R2, MSE, MAE)  
- Логистическая регрессия  (обучение, метрики качества: Log loss, ROC-AUC, Accuracy, Precision, Recall, F1, матрица ошибок)
