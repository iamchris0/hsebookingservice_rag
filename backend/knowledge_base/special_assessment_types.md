# Особенности организации оценивания по отдельным элементам обучения
*Раздел V Положения*

---

## 1. Независимые экзамены

### 83–86. Общие положения
- **83.** Перечень независимых экзаменов определяется учебным планом[^21];
- **84.** Участие в независимых экзаменах, указанных в учебном плане, обязательно;
- **85.** Независимый экзамен может иметь факультативные или обязательные Дисциплины-пререквизиты;
- **86.** Характеристики определяются в Программе НЭ или иных локальных актах.

[^21]: Как правило, элемент называется «Независимый экзамен по …» или содержит слова «независимый экзамен». Допускается отнесение к независимым экзаменам элементов с другим названием, что должно быть отмечено в программе или локальных актах.

### 87–88. Регулирование по типам экзаменов
- **87.** Особенности проведения независимого экзамена по английскому языку – Приложения 2–4; по РКИ – по аналогии с английским;
- **88.** Особенности проведения независимых экзаменов по цифровым компетенциям – Приложение 5.

### 89–92. Организация и сроки
- **89.** Дисциплины-пререквизиты могут не иметь экзаменов → окончательная оценка выставляется на основании оценки по независимому экзамену;
- **90.** Студент может отказаться от обязательных пререквизитов или заменить их по согласованию с академическим руководителем;
- **91.** При оценивании на разных уровнях студент может инициативно участвовать на более высокий уровень;
- **92.** Независимые экзамены могут проводиться не только в сессию. Сроки, резервные дни и пересдачи устанавливаются локальными актами. Студент может пройти экзамен раньше при наличии свободных слотов.

### 93. Учёт задолженностей между периодами пересдач
Для английского языка, РКИ и цифровых компетенций:
| Ситуация | Учёт задолженности |
|----------|-------------------|
| **93.1.** Положительная оценка по пререквизиту + задолженность по независимому экзамену | Добавляется к общему количеству |
| **93.2.** Задолженность по пререквизиту | Задолженность по независимому экзамену не добавляется |
| **93.3.** Задолженности по нескольким экзаменам одной группы | Учитываются как одна академическая задолженность |

### 94. Взаимный зачёт результатов
Положительные результаты независимого экзамена и пререквизита подлежат взаимному зачёту[^22]:
- **94.1.** Оценка за независимый экзамен учитывается как пересдача по пререквизиту с задолженностью → задолженность ликвидируется[^23];
- **94.2.** Оценка за независимый экзамен учитывается по обязательному пререквизиту, который студент не изучал, но просит включить в ИУП;
- **94.3.** Оценка за независимый экзамен по цифровым компетенциям учитывается по пререквизиту, если выше оценки по пререквизиту;
- **94.4.** Оценка за пререквизит учитывается по независимому экзамену, если выше и по экзамену нет задолженности[^24].

[^22]: Оформление зачёта производится в УИС при контроле менеджера программы.  
[^23]: Менеджер оформляет ведомость с перезачтёнными результатами и вносит изменения в УИС.  
[^24]: В случае оценки >8 баллов для целей зачёта используется оценка 8.

### 95–96. Зачёт при переходе между программами
- **95.** Не может быть зачтен результат независимого экзамена более низкого уровня для экзаменов с уровнями;
- **96.** При зачёте результатов из программы без независимого экзамена (восстановление, перевод, выход из отпуска) независимый экзамен не подлежит зачёту и назначается в ИУП[^25].

[^25]: Включение Дисциплины-пререквизита в ИУП происходит по желанию студента.

## 2. Внешняя оценка

### 97–101. Обязательность и учёт
- **97.** Внешняя оценка, предусмотренная учебным планом или распорядительными документами, обязательна;
- **98.** Неявка на обязательную внешнюю оценку = академическая задолженность;
- **99.** Пропуск по уважительной причине не суммируется с задолженностями по независимому экзамену/пререквизиту;
- **100.** Неудовлетворительная оценка по внешней оценке не учитывается как задолженность;
- **101.** При пропуске по уважительной причине Университет создаёт условия для прохождения; при пропуске без уважительной причины – студент может пройти оценку на условиях организации-проведителя в течение 6 месяцев. По истечении 6 месяцев без прохождения – учебный план считается не выполненным.

### 102. Зачёт результатов внешней оценки
| Тип внешней оценки | Условия зачёта |
|-------------------|----------------|
| **102.1.** Иностранный язык | Сертификаты по Концепции развития иноязычной компетенции с оценкой ≥ «хорошо». Заявка в ЭИОС за 5 рабочих дней до экзамена/сессии с копией сертификата. После проверки – внесение оценки в УИС, студент не включается в ведомость. |
| **102.2.** Английский язык / Project Proposal | Зачёт положительной оценки внутренней оценки результатом внешней оценки **не предусмотрен**. |
| **102.3.** Цифровые компетенции[^26] | Зачёт, если: (1) предыдущая оценка по независимому экзамену положительная и ниже внешней; (2) нет предыдущей внешней оценки, большей текущей на ≥2 балла. |

[^26]: Результаты зачёта сертификатами обновляются автоматически 1 раз в год после сессии 4 модуля до 10 июля. Правило пересчёта – в Приложении 5.

### 103. Аннулирование зачётов при снижении внешней оценки
Если очередная внешняя оценка ниже любой предыдущей на ≥2 балла:
- Все ранее проведённые зачёты на лучшую оценку аннулируются;
- В УИС восстанавливаются ранее полученные результаты независимых экзаменов и пререквизитов;
- Образовавшиеся задолженности подлежат пересдаче в ближайший возможный период.

### 104. Организация внешней оценки по цифровым компетенциям
Описана в Приложении 5 к Положению.

## 3. Факультатив «Академическое письмо на английском языке» и защита Project Proposal

### 1–3. Назначение и участие
- **1.** Студентам выпускного курса бакалавриата/специалитета предлагается факультатив «Academic Writing» для помощи в работе с англоязычными ресурсами при выполнении ВКР;
- **2.** По итогам освоения студент создаёт развёрнутый план ВКР на английском (Project Proposal) – неотъемлемая часть ВКР;
- **3.** Студенты могут не включать факультатив в ИУП и готовить Project Proposal самостоятельно.

### 4–8. Проверка и защита
- **4.** Project Proposal проверяется на плагиат в установленном порядке[^27] в сроки, определённые академическим руководителем;
- **5.** Защита Project Proposal перед комиссией обязательна независимо от наличия факультатива. Процедуру и состав комиссии регламентирует академический руководитель в программе практики;
- **6.** Рекомендуется защита в сессию 3 модуля; не позднее 2 недель после 3 модуля выпускного курса;
- **7.** Результаты фиксируются в протоколе, который готовит менеджер программы;
- **8.** Неудовлетворительная оценка или неявка без уважительной причины = академическая задолженность → применяется порядок Раздела VIII.

[^27]: Регламент организации проверки письменных работ на плагиат, использование генеративных моделей и размещение ВКР на корпоративном сайте НИУ ВШЭ.

### 9–11. Учёт результатов
- **9.** Оценки передаются секретарю ГЭК по защите ВКР;
- **10.** Оценка указывается отдельной строкой в приложении к диплому;
- **11.** При изменении темы ВКР или подготовке нового текста восстановленным студентом – включается раздел с аналогом Project Proposal на английском. Требования к структуре могут быть установлены в программе практики; при отсутствии – студент излагает в свободной форме.

## 4. Практическая подготовка

### 12–16. Оформление оценок
- **12.** Оценки за ЭПП выставляются в ведомость или оценочный лист[^29]. Ведомость допускается при >20 студентов или по согласованию с академическим руководителем. Сроки сдачи в учебный офис:
  - При несовпадении с окончанием модуля: ≤5 рабочих дней после окончания ЭПП;
  - Летний период: ≤первой недели будущего учебного года;
  - Равномерное распределение: ≤5 рабочих дней после сессии 4 модуля;
- **13.** В ведомости/листе указываются: вид практики, тип ЭПП, наименование (проект, тема курсовой/ВКР);
- **14.** При защите перед комиссией оценка выставляется решением комиссии, ведомость заполняет председатель;
- **15.** Неявка на защиту отмечается как «неявка»;
- **16.** Руководитель ЭПП/председатель комиссии несёт ответственность за получение и возврат ведомости через ЭИОС.

[^29]: Форма оценочного листа приведена в Положении о практической подготовке студентов НИУ ВШЭ.

## 5. Дисциплины, изученные в других организациях при академической мобильности

### 17–18. Учёт результатов
- **17.** Результаты промежуточной аттестации студентов, освоивших часть программы в другой организации (в т.ч. зарубежной), учитываются путём зачёта в соответствии с локальными актами НИУ ВШЭ;
- **18.** Оценки определяются индивидуально для каждого студента в установленном порядке[^30].

[^30]: Согласно Положению о порядке проведения аттестации и зачёта результатов предыдущего образования при освоении образовательных программ высшего образования в НИУ ВШЭ.
