# 1. Обзор внешней оценки/внешнее измерение/иннополис

## 1.1. Контекст «Приоритет 2030»

НИУ ВШЭ участвует в программе «Приоритет 2030» вместе с 105 университетами России.  
**Ключевой показатель:** доля выпускников, подтвердивших квалификацию по ИТ-направлению.

## 1.2. Модуль Data Culture

Обязательный модуль для формирования цифровой квалификации, включающий проверку **трёх компетенций**:

- Цифровая грамотность
- Программирование
- Анализ данных

## 1.3. Переход с платформы Иннополиса на платформу НИУ ВШЭ

Исторически внешняя оценка проводилась на платформе Университета Иннополиса (тесты в три этапа: входная, промежуточная, итоговая оценка). **С набора 2023 года платформа Иннополиса больше не используется** — вся сдача перенесена на платформу НИУ ВШЭ.

**Текущий порядок в зависимости от ситуации студента:**

| Ситуация | Что нужно сделать | Платформа |
| -------- | ----------------- | --------- |
| **Набор 2023 и позже** (3 курс) | Сдать только итоговый проект | [edu.hse.ru — итоговый проект](https://edu.hse.ru/course/view.php?id=273033) |
| **Начинали сдавать в Иннополисе**, но не завершили все этапы | Досдать недостающие тесты + проект на платформе НИУ ВШЭ | [edu.hse.ru — курс для досдачи](https://edu.hse.ru/course/view.php?id=253000) |

> ⚠️ **Важно:** Студентам набора 2023+ не нужно сдавать входную и промежуточную оценку — только итоговый проект.

## 1.4. Перезачёт оценок

Результаты внешней оценки могут повысить баллы по независимому экзамену и дисциплине-пререквизиту:

| Этап оценки          | Повышает балл по дисциплине |
| -------------------- | --------------------------- |
| Входная оценка       | Цифровая грамотность        |
| Промежуточная оценка | Программирование            |
| Итоговая оценка      | Анализ данных               |

> ⚠️ Для студентов 3 курса (набор 2023+) перезачёт идёт только по итоговому проекту.

# 3. Формат итогового проекта (с 2025/26)

## 3.1. Общие положения

| Параметр                  | Значение                                     |
| ------------------------- | -------------------------------------------- |
| **Формат**                | Индивидуальный итоговый проект               |
| **Оценка**                | 100% — проект (тесты отключены)              |
| **Проходной порог**       | ≥ 3.5 баллов (10-балльная шкала) → **ЗАЧЁТ** |
| **Формат сдачи**          | Один файл `.ipynb` (Jupyter Notebook)        |
| **Язык программирования** | Только **Python**                            |

## 3.2. Типы проектов по уровням

| Уровень         | Доступные типы проектов                                                                   |
| --------------- | ----------------------------------------------------------------------------------------- |
| **Начальный**   | • Общий (интерактивная история)<br>• Отраслевые кейсы (гуманитарные, общественные и т.д.) |
| **Базовый**     | • Общий проект<br>• Гуманитарные науки<br>• Естественные науки<br>• Общественные науки    |
| **Продвинутый** | • Только расширенная интерактивная история (≥10 сцен, классы, алгоритмы, параметры)       |

## 3.3. Краткие требования по типам проектов

| Тип проекта                       | Доступен            | Мин. строк данных | Ключевые требования                                    |
| --------------------------------- | ------------------- | ----------------- | ------------------------------------------------------ |
| Интерактивная история (базовая)   | Начальный + Базовый | —                 | ≥5 концовок, запись в `.txt`, блок-схема               |
| Гуманитарные науки                | Начальный + Базовый | 100               | ≥5 показателей, запись в `.txt`, `open()/readline()`   |
| Естественные науки                | Начальный + Базовый | 100               | ≥5 статистик, запись в `.txt`                          |
| Общественные науки                | Начальный + Базовый | 100               | ≥5 статистик, запись в `.txt`                          |
| Расширенная интерактивная история | Только продвинутый  | —                 | ≥10 сцен, ≥5 концовок, код в виде класса, 2+ алгоритма |

# 6. FAQ (частые вопросы)

## 6.1. Изменения в системе оценки

**В:** Почему убрали тесты?
**О:** Тесты отключены из-за высокой нагрузки на систему. Теперь оценка выставляется только по проекту.

**В:** Что если я уже сдал тесты?
**О:** Будет выбрана максимальная оценка из проекта и тестов (в пользу студента).

**В:** Что если тесты не сдавал?
**О:** Будет учтена только оценка за проект.

## 6.2. Формат и выбор проекта

| Вопрос | Ответ |
|--------|-------|
| Проект индивидуальный или групповой? | Только индивидуальный |
| Как узнать свой уровень сложности? | По ссылке на документ |
| Можно ли выбрать кейс не по своей программе? | Да, кроме ИТ-программ (они обязаны брать продвинутый уровень) |
| Где найти задания? | В курсе на edu.hse.ru — перейдите в нужное задание для описания и критериев |

## 6.3. Технические вопросы

**В:** Почему нельзя использовать pandas/numpy?
**О:** Это требование автопроверки. Использование сторонних библиотек ведёт к штрафу по баллам.

**В:** Нужно ли прикреплять файл с данными?
**О:** Нет, только `.ipynb`. Файл с данными обрабатывается внутри кода.

**В:** Что значит «структуры данных применяются по назначению»?
**О:** Структуры (`list`, `dict`, `set`) должны быть частью логики решения, а не добавлены формально.

## 6.4. Оценивание и зачёт

| Вопрос | Ответ |
|--------|-------|
| Кто проверяет проект? | Автоматическая система + выборочная ручная проверка преподавателем |
| Что проверяет автотест? | Работоспособность кода, соответствие критериям, антиплагиат |
| Идёт ли оценка в диплом? | Нет. В зачётку ставится **ЗАЧЁТ** при оценке ≥ 3.5. Рейтинг не влияет. |
| Есть ли перезачёт с НЭ по Иннополису? | Нет, оценка за проект не участвует в перезачёте с независимым экзаменом |
| Влияет ли отрицательная динамика? | Нет, для студентов 3 курса отрицательная динамика не влияет на перезачёты |

## 6.5. Технические проблемы

- 🔴 **Ошибка 504 / Connection refused** → Перезагрузите проект, сервер временно недоступен
- 🔴 **Тест не сформировался после отправки** → Нормально. Тесты отключены, ожидайте оценку за проект
- 🔴 **Появилось несколько одинаковых тестов** → Игнорируйте. Оценка базируется только на проекте
- 🔴 **Сбой во время теста** → Перезагрузите задание (удалите и загрузите заново), появится новый тест
- 🔴 **Долго не приходит оценка** → Проверка идёт в фоновом режиме. Если прошёл день — ожидайте, все получат оценку
- 🔴 **Не успел сдать из-за технических проблем** → Восстановить сдачу можно на открытом курсе: [https://edu.hse.ru/course/view.php?id=273033](https://edu.hse.ru/course/view.php?id=273033)

> 💡 **Важно:** Организаторы продлевают дедлайны при технических сложностях. Главное — не паниковать и обратиться в учебный офис при необходимости.
